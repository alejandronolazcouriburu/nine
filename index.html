📖 Guía de Cuadrantes

Alto Potencial
⭐ Estrella (R1)

Alto Performance / Alto Potencial - Constantemente se desempeña bien en una variedad de tareas; empleado superestrella. Piensa en grande; solucionador de problemas; auto motivado.

Futura Estrella (R2)

Medio Performance / Alto Potencial - Le va extremadamente bien en el trabajo actual con potencial para hacer más; establece asignaciones para ayudarlo a prepararse para el próximo nivel.

Disfuncional (R5)

Bajo Performance / Alto Potencial - Profesional experimentado capaz de ampliar su rol, pero puede estar experimentando problemas que requieren entrenamiento y orientación.

Potencial Medio
Alta Performance (R3)

Alto Performance / Medio Potencial - El rol actual aún puede brindar oportunidades de crecimiento centrado en lo táctico; El enfoque debe ser ayudar a mejorar su pensamiento estratégico.

Empleado Clave (R6)

Medio Performance / Medio Potencial - Puede considerarse para la ampliación del empleo al mismo nivel, pero puede necesitar entrenamiento en varias áreas, incluida la gestión de personas.

Dilema (R8)

Bajo Performance / Medio Potencial - Con el entrenamiento adecuado podría progresar dentro del nivel; enfócate en las metas para este empleado.

Bajo Potencial
Excelente Profesional (R4)

Alto Performance / Bajo Potencial - Experimentado y de alto rendimiento pero ha alcanzado el límite del potencial profesional. Sigue siendo un empleado valioso y puede ser alentado a desarrollar habilidades de comunicación y delegación.

Buen Desempeño (R7)

Medio Performance / Bajo Potencial - Ejecutante efectivo, pero puede haber alcanzado el potencial profesional; trate de entrenar a los empleados para que sean más innovadores.

⚠️ Considerar Despido (R9)

Bajo Performance / Bajo Potencial - Puede ser candidato para reasignación, reclasificación a un nivel inferior o para salir de la organización.
