# 9 Boxes - Equipo CIS

Matriz de evaluación de talento para el equipo CIS.

## 🔒 Acceso

Contraseña: `CIS2026`

## 📊 Estructura

- **5 Líderes**: Priscila, Bruno, Mauro, Carolina, Jano
- **1 Vista Consolidada**: Todos los equipos juntos

## 🎯 Uso

1. Ingresa con la contraseña
2. Ve a tu pestaña de equipo
3. Agrega analistas con nombre + seniority
4. Arrastra al cuadrante correspondiente
5. Posiciona con precisión dentro del cuadro
6. Los datos se guardan automáticamente

## 📥 Exportar

Cada líder puede exportar su equipo a CSV desde su pestaña.
